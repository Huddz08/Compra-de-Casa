# Atualização: excluir listas

1. Extraia atualizacao-excluir-lista.zip.
2. No GitHub, use Add file → Upload files e envie os arquivos extraídos para a raiz do repositório, substituindo os existentes.
3. Confirme em Commit changes e aguarde a publicação da Vercel.
4. Recarregue o aplicativo no celular.

Abra a lista → Editar dados → Excluir essa lista → confirme.
A exclusão é salva imediatamente; não é necessário tocar em Salvar lista.
Excluir uma compra concluída remove sua participação nos gráficos e no histórico de preços. Produtos cadastrados e outras listas, inclusive pendências, permanecem.

Não é necessário alterar o Firebase ou config.js.
